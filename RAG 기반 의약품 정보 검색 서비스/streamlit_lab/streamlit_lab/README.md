# 의약품 정보 검색 챗봇 서비스

`실행.cmd`를 두 번 클릭하면 http://localhost:8502 를 브라우저로 엽니다. 이미 실행 중이면 기존 앱을 열고, 꺼져 있으면 서버를 시작합니다. 성공 후 실행 창이 닫혀도 서버는 계속 동작합니다. 화면이 이전 상태라면 Ctrl+F5로 새로고침하세요.

자동으로 브라우저가 열리지 않으면 위 주소에 직접 접속하세요. 시작 실패 기록은 `data/hospital/project/storage/logs/server.log`에 저장합니다.

## 질문 방법

- “가스터가 뭐야?”처럼 기본 설명은 약 이름만으로 질문합니다.
- 기본 설명 아래 **제품별로 자세히 보기**를 펼치면 정확한 제품을 선택할 수 있습니다.
- 용량·투여방법·희석·병용 등 제품별 차이가 중요한 질문에서만 함량·제형을 확인합니다.
- 약 기본정보 대화와 정확한 제품 대화의 기록을 구분합니다.
- 제목 아래 **검색 가능한 약 목록**에서 제품 후보를 확인할 수 있습니다.

## 자료 범위

제공된 PDF의 약 이름 43개 항목에서 찾은 식약처 정상 허가 제품 후보 233개입니다. 병원 채택이 확정된 233개 약 목록은 아닙니다. 식약처 공식 문서와 원문 출처를 활용하며, 공부용 설명과 예시 약은 답변 근거에서 제외했습니다. 약학정보원·성인간호학·병원 자체 지침은 아직 연결하지 않았습니다.

여러 제품을 확인한 기본 설명을 모든 함량·제형에 공통인 정보로 확대하지 않습니다. 표·너무 긴 문서 등 확인이 보류된 자료가 있으면 그 한계를 안내합니다.

## 파일 역할

- `hospital_app.py`, `hospital_chat.py`: 실행과 화면
- `drug_pipeline.py`, `drug_overview.py`: 질문 해석·기본 설명·제품별 검색·답변
- `drug_core.py`, `drug_sources.py`: 모델·색인·공식 자료 연결
- `collect_hospital.py`, `collect_hospital_documents.py`: 후보와 공식 PDF 수집
- `prepare_hospital.py`, `build_drug_dataset.py`, `prepare_drugs.py`: 변환·청킹
- `index_hospital.py`, `index_drugs.py`: 병원 전용 검색 색인
- `prompts/`, `rag_settings.json`: 데이터 갱신에 사용하는 원본 설정
- `data/hospital/project/`: 실제 검색 데이터·설정·색인 상태
- `.env`: 로컬 키. 외부에 공유하지 않습니다.

## 검증

```powershell
.\.venv_drug\Scripts\python.exe -m unittest test_project test_overview test_sources -q
```

기능·화면 회귀 검사 24건과 실제 모델의 기본 질문→벡터 검색·인용→후속 용량 확인 흐름을 검증했습니다. 고정 프롬프트 사례 7개는 변경 전 6개·변경 후 7개가 통과했으며 전체 임상 정확도를 입증하는 수치는 아닙니다.

자료 갱신 방법은 `병원모드_안내.md`를 참고하세요. 모델 설정은 실행 중인 `data/hospital/project/rag_settings.json`에서 변경합니다. 자료를 다시 준비할 때는 루트 `rag_settings.json`이 복사되므로 모델을 계속 유지하려면 두 설정을 맞춰 두세요.

본 서비스는 정보 조회·학습을 지원하며 환자별 투약 판단을 대신하지 않습니다.

## 추가 근거와 프롬프트

다섯 프롬프트는 프로젝트 루트 `prompts/`에서 편집하며 다음 요청부터 읽습니다. `external_sources.py`는 사용 권한과 제품 범위가 확인된 추가 자료를 등록·복원하며, `source_ui.py`는 등록 화면입니다.
왼쪽 **근거 자료 추가 · 약학정보원 / 병원 지침**에서 권한이 확인된 PDF/TXT 또는 본문을 등록할 수 있습니다. 약학정보원 본문은 현재 0건이며 자동 전체 수집하지 않았습니다.

자세한 내용은 `프롬프트_자료추가_안내.md`와 `명세서_점검.md`를 참고하세요. 현재 프로토타입을 명세서 전체 완료로 표시하지 않으며 표의 구조 검증·필수 문서 색인, 예외 상황 증빙, 선택 심화와 제출 문서가 남아 있습니다.

## 응답 속도

기본 설명 질문은 제품명 직접 일치를 확인한 경우 질문 해석·검색 계획의 AI 호출을 생략합니다. 조건 탐색·용량·비교·후속 질문은 기존 해석을 유지합니다. 답변 생성 모델과 근거 인용 검증은 유지합니다.
질문 시 식약처 목록 재조회는 기본적으로 끕니다. 저장된 자료 기준이며 실시간 최신 확인은 아닙니다. `retrieval.refresh_sources_on_query`를 true로 바꾸면 기존 조회를 다시 사용합니다. 단계별 AI 처리 시간은 events.jsonl의 duration_seconds에 기록합니다.
