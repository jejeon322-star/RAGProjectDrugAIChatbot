## 다섯 프롬프트 변경

편집 기준을 프로젝트 루트의 `prompts/` 한 곳으로 통일했습니다. 프롬프트 해시를 호출 로그에 남깁니다. 실제 파일을 수정하면 다음 요청부터 읽으며, 모델 자체의 파인튜닝을 수행한 것은 아닙니다.

| 파일 | 수정한 핵심 |
|---|---|
| interpret.txt | 기본 설명·일반 주의·제품별 상세를 구분하고, 기본 질문은 선택 없이 진행. 후속 질문과 새 제품을 구분. 전체 JSON 스키마와 분류 예시 제공 |
| search.txt | API 제품명 검색과 벡터 검색 질문을 분리. 실제 제품명만 source_queries에 출력. 주제·부정 조건 유지 |
| select.txt | 선택 제품 자체 허가자료는 강제 포함. 추가 자료의 제품·제형·범위를 검토. 모호한 자료는 보류. 필수 문서의 이유를 반복 생성하지 않음 |
| answer.txt | 첫 문장부터 핵심 답변. 주장별 인용·제품 범위·출처 역할·충돌 처리 강화. 미확보 정보와 안전 판단을 구분. 기본 설명에서 복용·투여 지시 제외 |
| explore.txt | 모든 조건 및 부정 조건을 개별 확인. 원문에 실제 있는 연속 문자열만 근거 인용. 환자별 약 추천 제외 |

기본 라우팅, 검색, 선별, 답변, 조건 탐색의 역할이 이미 다섯 개에 나뉘어 있어 추가 LLM 검토 단계를 늘리지는 않았습니다. 대신 인용 ID·제품 범위·입력 검증과 테스트를 보강했습니다. 역할·예시·출력 형식을 명시하고 평가로 확인하는 방식은 [OpenAI 프롬프트 안내](https://developers.openai.com/api/docs/guides/prompt-engineering)를 참고했습니다.

## 프롬프트 외 함께 고친 부분

- 기본 설명도 저장 문서 직접 읽기로 끝내지 않고, 검색 계획 → 벡터 검색 → Top-k·중복 제거 → 답변을 거칩니다.
- 추출한 source_queries가 실제 외부 API 검색에 사용되도록 연결했습니다. 선택 제품 자체 검색은 유지합니다.
- 모든 후보가 강제 포함 문서라면 결과가 바뀌지 않는 추가 선별 LLM 호출을 생략합니다. 선택 가능한 추가 후보가 있거나 새 자료를 등록할 때는 선별 프롬프트를 사용합니다.
- 최근 외부 검색 실패는 5분 동안 재시도 대기를 반복하지 않도록 기록합니다. 정상 검색 결과는 기존 24시간 캐시를 사용합니다.
- 식약처 허가자료와 추가 근거 문서를 구분하여 제목·출처·URL 또는 파일·쪽수·명시된 판본을 표시합니다.

## 약학정보원 등록 방법

왼쪽 **근거 자료 추가 · 약학정보원 / 병원 지침**을 펼칩니다.

1. 자료를 연결할 정확한 제품을 선택합니다.
2. 출처를 약학정보원으로 선택하고 문서 제목·해당 문서의 health.kr 상세 주소를 입력합니다.
3. 사용 권한이 있는 PDF/TXT 파일을 올리거나 검토한 본문을 붙여넣습니다. 주소만 입력한 경우 본문을 자동으로 수집하지 않습니다.
4. 원문 위치·판본·개정일과 구체적인 이용 권한 근거를 기록합니다. 권한 및 선택 제품의 적용 범위를 확인합니다.
5. **자료 검토 후 검색에 반영**을 누릅니다. 후보 선별 → 청킹 → 현재 검색 DB 반영을 진행합니다. 관련성이 불명확하면 보류 상태로 저장합니다.

등록 후 해당 제품을 선택하여 질문합니다. 실제 사용된 추가 문서는 답변 아래에 식약처 자료와 구분해 표시합니다. 원본과 출처 기록을 보관하며, 데이터 준비를 다시 실행해도 추가 자료를 복원합니다. 같은 출처·제목·제품·판본으로 재등록하면 문서 정체성을 유지합니다.

PDF는 5MB·30쪽 이하이며 텍스트 추출 가능한 자료를 사용합니다. 표가 감지되거나 문자가 깨졌다면 원문과 대조한 텍스트로 준비합니다. 본문은 적용 조건이 온전한 40~16,000자 독립 절을 등록합니다. 등록된 모든 자료가 곧 임상 검토 완료라는 뜻은 아닙니다.

## 약학정보원 본문을 자동으로 넣지 않은 이유

[약학정보원 법적 책임 안내](https://www.health.kr/notice/legal)는 제공 정보의 저작권을 명시하고 허락 없는 이용에 대한 제한을 안내합니다. [서비스 이용약관](https://www.health.kr/notice/terms)에도 사전 승낙 없는 복제·제공 제한이 있습니다. 공개 열람과 챗봇 DB 저장·AI 처리·재제공 권한을 같은 것으로 취급하지 않았습니다.

이번 작업은 사용 권한을 확보한 자료의 등록 기능을 구현한 것이며, 약학정보원 본문을 실제 수집·색인한 건수는 현재 0건입니다. 사용 허락 자료나 계약된 데이터가 준비되면 이 경로로 추가할 수 있습니다. 환자 개인정보가 담긴 자료는 등록하지 않습니다.
